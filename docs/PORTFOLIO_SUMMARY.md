# Portfolio description (accurate scope)

**Mixed Finite Element Analysis of Timoshenko Beams**

Original graduate course project: **2017 (Tir 1396)**. Modern Python
reconstruction and additional independent verification: **November 2026**.

Implemented and tested a mixed finite element solver for static and dynamic
Timoshenko beams, including force assembly, boundary conditions, source-derived
mass/stiffness matrices, time integration, stress recovery, and mesh studies.
A separate displacement–rotation FEM model and an exact simply supported
Timoshenko frequency were developed to independently validate the numerical
results. The software includes automated tests, reproducible figures and CSV
outputs, and a detailed audit of inconsistencies in the historical report.

**Important:** The historic source plotted static deflection remains
unreconciled; therefore do not claim a completed validation against the
reported historical Abaqus output. All 2026 improvements are identified
as new work. The archival 2017 course document is not included.
