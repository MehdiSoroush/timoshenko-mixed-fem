# Project history and attribution

- **2017 (Tir 1396):** Original graduate-level coursework project on mixed finite element methods for Timoshenko beams, including static/dynamic MATLAB analysis and reported Abaqus comparisons.
- **November 2026:** Reimplementation of the mathematical and numerical model as independently executable, documented Python software, with additional numerical tests and modal verification.

The archival 2017 course report is intentionally **not uploaded** to GitHub. Dates are provided as provenance, not as evidence that all 2026 code existed in 2017.

The current Python source files, automated tests, additional Newmark method, and visualizations constitute a modern reconstruction. Reported historical plots or Abaqus outputs should not be described as independently reproduced until the corresponding numerical verification has been performed.
